# MH Studio — Static website

موقع عربي متجاوب مناسب لـ GitHub Pages. المحتوى الأساسي مكتوب مباشرة داخل ملفات HTML؛ لذلك لا يعتمد ظهور الصفحات على JavaScript.

## الملفات
- `index.html` — الصفحة الرئيسية
- `styles.css` — التصميم والتجاوب
- `script.js` — قائمة الهاتف، السنة، ونموذج البريد
- `contact.html` — صفحة التواصل
- `services/` — صفحة مستقلة لكل خدمة

## النشر على GitHub Pages
1. فك ضغط الحزمة.
2. ارفع جميع الملفات والمجلدات إلى جذر فرع `main` في المستودع، مع الحفاظ على بنية المجلدات.
3. من Settings → Pages اختر النشر من فرع `main` ومجلد `/(root)`.
4. افتح الموقع مع تحديث قوي للصفحة (Ctrl+Shift+R أو Cmd+Shift+R).

## ملاحظة مهمة
عنوان البريد `hello@mhstudio.example` عنوان تجريبي، ويجب استبداله ببريدك الحقيقي في `contact.html` وفي `script.js` قبل النشر. نموذج التواصل يفتح تطبيق البريد على جهاز الزائر ولا يرسل البيانات إلى خادم.
