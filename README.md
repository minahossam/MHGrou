# MH Studio — GitHub Pages

موقع عربي RTL متعدد الصفحات لهوية MH التقنية. يتضمن صفحة رئيسية، صفحات مستقلة للخدمات، ونموذج طلب خدمة.

## النشر على GitHub Pages
1. فك ضغط الحزمة.
2. ارفع **محتويات المجلد** إلى جذر فرع `main` في مستودع GitHub، مع الحفاظ على مجلد `services` و`assets`.
3. من Settings → Pages اختر النشر من `Deploy from a branch` ثم `main` و`/(root)`.
4. بعد اكتمال النشر افتح الموقع وحدّثه تحديثًا قويًا.

## إعداد مهم قبل استقبال الطلبات
افتح `contact.html` وابحث عن `REPLACE_WITH_REAL_EMAIL` واستبدله بعنوان البريد الذي تريد استقبال الطلبات عليه، في خاصية `data-recipient`. نموذج الطلب يستخدم تطبيق البريد لدى الزائر (mailto) ولا يرسل البيانات إلى خادم. للحصول على إرسال مباشر دون تطبيق بريد، ستحتاج إلى خدمة نماذج أو backend وربطها بشكل منفصل.

## الملفات
- `index.html`: الصفحة الرئيسية
- `styles.css`: التصميم والتجاوب والحركة
- `script.js`: القائمة والتأثيرات ونموذج الطلب
- `contact.html`: نموذج الطلب
- `services/`: صفحات تفصيلية لكل خدمة
- `assets/favicon.svg`: أيقونة الموقع

تم تصميم المحتوى ليظهر دون الاعتماد على JavaScript. الخطوط الخارجية اختيارية؛ في حال عدم توفرها سيستخدم المتصفح خطًا بديلًا.
